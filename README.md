# Kaya: Lord of the Jungle

**Play it here: https://deanmalhotramusic-maker.github.io/kaya-lord-of-the-jungle/**

A 3D jungle action game made with Unity 6. Kaya, raised by apes, walks through five glowing stone rings to fight five beasts:

1. **The Clearing**: Brutus, the Silverback Gorilla
2. **Golden Savanna**: Raja, the Striped Tiger
3. **Web Cave**: Venomira, the Spider Queen
4. **Misty Swamp**: Old Jaws, the Giant Alligator
5. **Thunder Peak**: Gorak, the Mountain Ape (final boss)

Works in desktop and phone browsers. On a phone, turn it sideways. You get a joystick plus HIT, SPEAR, JUMP, ROLL, BLOCK and ROAR buttons.

**Keyboard:** WASD move, mouse look, Shift sprint, Space jump (press twice for a double jump), left click / J attack, K arrow, right click / Q block (tap just before a hit to parry), C / L roll, R Jungle Fury, Tab lock-on, P pause.
